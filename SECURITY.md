# Security

Wijeti beta builds are ad-hoc signed and not notarized; see [INSTALL.md](INSTALL.md) for how to
verify a download (SHA-256) and open it safely. Updates are verified with an EdDSA signature.

Report a vulnerability privately through GitHub's **Security → Report a vulnerability** on this
repository rather than a public issue. Include the version, chip (Apple Silicon or Intel) and steps to
reproduce.
